# Tai Chi Sword Selection

Help the user pick a specific, purchase-ready tai chi sword configuration: blade length, weight, material, and budget. Always end with concrete numbers, not generic advice.

## Step 0: Triage the scenario

Identify which situation applies, then follow the matching path:

| Scenario | Path |
|---|---|
| First sword, no details given | Give the default answer (below), then offer to refine with their height |
| User gives height and/or experience | Run the full 5-step workflow |
| Buying a gift | Use recipient's height in the size chart; default to mid-range stainless steel, 450–550g |
| Child or indoor-only form practice | Wooden sword; see [references/materials.md](references/materials.md) |
| Competition or performance | Competition rules override the size chart — check the event's regulations first, then size within the allowed range |
| Humid climate (e.g., Florida, Gulf Coast) or low-maintenance user | Steer away from carbon steel; see [references/materials.md](references/materials.md) |
| Wrist/shoulder issues or smaller frame (under 130 lbs) | Cap at 550g, ideally 400–500g; see [references/weight-guide.md](references/weight-guide.md) |
| Double sword (shuang jian) practice | Size one increment shorter than the chart; weight at the low end per sword |

**Default answer when the user gives no details:** a stainless steel sword with a 28–30 inch blade, ~500g total weight, priced $80–130, from a tai chi specialist retailer. This fits the average adult beginner.

## The 5-step selection workflow

Run these in order. Each step links to a reference file with the full decision tables — read the reference when you need the details.

### 1. Size — blade length by height
Rule of thumb: stand the sword tip-down; the pommel should reach between the navel and the eyebrow. On a borderline height, go shorter, not longer. Adjust for arm length. Distinguish blade length from total length (some sellers quote total length to sound bigger).
→ Tables and adjustment rules: [references/size-chart.md](references/size-chart.md)

### 2. Weight — by skill level and body type
Weight means total weight including the scabbard. Beginners: 400–550g; intermediate: 550–700g; advanced: 700–800g. Tai chi sword is about control, not power — when in doubt, go lighter.
→ Tiers and body-type adjustments: [references/weight-guide.md](references/weight-guide.md)

### 3. Material — determines maintenance burden
Stainless steel is the default for 90% of practitioners (rust-resistant, near-zero maintenance). Carbon steel for traditionalists willing to oil the blade every 2–4 weeks. Wood for absolute beginners, kids, and indoor practice. Damascus/pattern steel is decoration, not function.
→ Comparison table and climate guidance: [references/materials.md](references/materials.md)

### 4. Budget — what each price tier actually buys
The sweet spot for a quality practice sword is $80–130. Below ~$50, balance and fittings are unreliable. Above $150, you're paying for aesthetics, not better practice.
→ Tier breakdown and red flags: [references/budget-tiers.md](references/budget-tiers.md)

### 5. Seller — specialist vs generalist
Tai chi swords have a specific balance profile different from wushu swords and other blades. Buy from a specialist that publishes weight, blade length, and balance specs, offers returns, and has reviews from actual practitioners.
→ Vetting checklist: [references/seller-checklist.md](references/seller-checklist.md)

## How to answer

- Give **one clear recommendation** with exact numbers (blade length in inches, weight in grams, material, price range), then briefly explain why. Offer one alternative at most.
- Ask **at most one clarifying question** — height is the highest-value unknown. If the user doesn't answer, state your assumption and proceed with the default.
- Use inches and grams (US buyers see both); add cm/lbs in parentheses when helpful.
- Warn about the common traps when relevant: buying too heavy, wrong length, carbon steel without maintenance commitment, generalist sellers relabeling wushu blades.
- For follow-up questions (balance testing, wushu vs tai chi swords, sharp vs dull edge, online vs in-store, wooden swords), see [references/faq.md](references/faq.md).
